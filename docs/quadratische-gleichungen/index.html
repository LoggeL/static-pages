Was ist eine quadratische Gleichung?

Eine Gleichung ist quadratisch, wenn die Variable x darin im Quadrat vorkommt – also x² – aber nie mit einer höheren Hochzahl wie x³.

Wichtig: Das x² darf beim Vereinfachen nicht wegfallen. Und manchmal versteckt es sich in einer Klammer.

✓ quadratisch

  • x² = 9
  • x² − 5x = 0
  • x² + 2x − 15 = 0
  • 3x² − 12 = 0
  • (x − 1)² = 4 versteckt in der Klammer
  • x(x + 4) = 7 denn x · x = x²

✗ nicht quadratisch

  • 3x + 7 = 1 kein x² → linear
  • x³ − x = 0 enthält x³
  • x² + 2x = x² − 6 x² fällt weg

Steht das x in einer Klammer, z. B. (x − 1)² oder x(x + 4)? Dann erst ausmultiplizieren – danach siehst du, ob ein x² übrig bleibt.

Welche Gleichungen sind quadratisch?

Lösung

Quadratisch sind x² − 5x = 0, (x − 1)² = 4 (ausmultipliziert: x² − 2x + 1 = 4) und 2x² = 18.

Nicht quadratisch: 3x + 7 = 0 (linear), x² + 2x = x² − 6 (nach | − x² bleibt 2x = −6) und x³ − x = 0 (enthält x³).

In Normalform bringen

Fast jede Aufgabe beginnt damit, die Gleichung aufzuräumen. Das Rezept hat vier Schritte:

  1. Klammern auflösen – ausmultiplizieren oder binomische Formel.
  2. Alles auf eine Seite – so, dass rechts 0 steht.
  3. Zusammenfassen und sortieren: erst x², dann x, dann die Zahl.
  4. Durch a teilen, falls vor x² keine 1 steht.

Beispiel Schritt für Schritt

  1. 2x(x + 3)= 4x + 12

    Links steht eine Klammer, rechts keine 0. Also: aufräumen.

  2. 2x² + 6x= 4x + 12| ausmultiplizieren

    2x · x = 2x² und 2x · 3 = 6x.

  3. 2x² + 6x − 4x − 12= 0| − 4x − 12

    Alles nach links. Auf beiden Seiten 4x und 12 abziehen – rechts bleibt 0.

  4. 2x² + 2x − 12= 0| zusammenfassen

    6x − 4x = 2x. Jetzt ist es die allgemeine Form mit a = 2.

  5. x² + x − 6= 0| : 2

    Jedes Glied durch 2 teilen – auch die −12. Fertig: Normalform mit p = 1 und q = −6.

Typische Fehler

  • Vorzeichen beim Rüberbringen: Aus + 4x rechts wird − 4x links.
  • Nur ein Glied geteilt: 2x² + 2x − 12 = 0 | : 2 ergibt x² + x − 6 = 0 – nicht x² + 2x − 12 = 0.
  • Binomische Formel vergessen: (x + 3)² ist x² + 6x + 9, nicht x² + 9.

Wie viele Lösungen?

Eine quadratische Gleichung hat zwei, eine oder keine Lösung. Am Bild siehst du sofort, warum: Die Lösungen von x² + px + q = 0 sind die Stellen, an denen die Parabel y = x² + px + q die x-Achse trifft.

Rechnerisch: x² = k

Am einfachsten siehst du es bei Gleichungen der Form x² = k („Wurzel ziehen“):

FallBeispielLösungsmenge
k > 0x² = 9L = {−3; 3}
k = 0x² = 0L = {0}
k < 0x² = −9L = { }

Warum? 3² = 9 und (−3)² = 9 – beide Zahlen passen. Nur 0² = 0. Und ein Quadrat ist nie negativ, also passt bei x² = −9 keine Zahl.

Eine quadratische Gleichung hat höchstens zwei Lösungen. Bei x² = k mit k > 0 sind es genau zwei: x = √k und x = −√k. Das „±“ nie vergessen!

Der Satz vom Nullprodukt

Das ist der wichtigste Satz für dieses Thema. Mit ihm löst du jede Gleichung, die als Produkt dasteht und rechts eine 0 hat.

Satz vom Nullprodukt

Ein Produkt ist genau dann null, wenn mindestens ein Faktor null ist.

A · B = 0  ⇔  A = 0 oder B = 0

Warum stimmt das? Probier es aus:

  • 7 · 0 = 0 ✓ ein Faktor ist 0
  • 0 · (−3) = 0 ✓ ein Faktor ist 0
  • 0,001 · 0,001 = 0,000001 winzig, aber nicht 0

Zwei Zahlen, die beide nicht 0 sind, ergeben nie 0 – egal, wie klein sie sind. Ist das Produkt also 0, muss ein Faktor 0 sein.

Kurz gemerkt

  • Quadratische Gleichung: ax² + bx + c = 0 mit a ≠ 0. Normalform: x² + px + q = 0.
  • Aufräumen: Klammern auflösen → alles auf eine Seite → sortieren → durch a teilen.
  • 0, 1 oder 2 Lösungen – nie mehr.

Grafisch lösen

Zu jeder quadratischen Gleichung gehört eine Parabel. Wo die Parabel die x-Achse schneidet, stehen deine Lösungen – du musst sie nur ablesen.

Die Idee in einem Satz

Die Lösungen von ax² + bx + c = 0 sind die Stellen, an denen die Parabel y = ax² + bx + c die x-Achse schneidet (oder berührt).

Nimm zum Beispiel x² − 2x − 3 = 0. Statt zu rechnen, zeichnest du die Parabel y = x² − 2x − 3.

Gesucht sind die x-Werte, für die y = 0 herauskommt. Auf der x-Achse ist y immer 0. Also sind die Lösungen genau die Schnittstellen mit der x-Achse – die Nullstellen.

Lösungen der Gleichung ax² + bx + c = 0
= Nullstellen der Parabel y = ax² + bx + c
= x-Werte der Schnittpunkte mit der x-Achse.

0, 1 oder 2 Lösungen – du siehst es sofort

Eine Parabel kann die x-Achse zweimal schneiden, sie nur berühren oder ganz an ihr vorbeilaufen. Genauso viele Lösungen hat die Gleichung.

📋 Wertetabelle – so geht’s

  • Nimm ganze x-Werte, etwa von −4 bis 4.

Typische Fehler – und wie du sie vermeidest

Fehler 1: y-Achsenabschnitt statt Nullstelle

Die Parabel y = x² − 2x − 3 schneidet die y-Achse bei −3. Das ist keine Lösung!

Lösungen liegen immer auf der x-Achse (der waagrechten Achse), also bei y = 0. Hier: L = {−1; 3}.

Fehler 2: Vorzeichen beim Scheitelpunkt

Bei y = (x − 2)² − 1 ist der Scheitel S(2 | −1) – nicht S(−2 | −1).

Merke: In der Klammer steht das Gegenteil. Frag dich, wann die Klammer null wird: x − 2 = 0 ⇔ x = 2. Wer den Scheitel falsch setzt, liest völlig falsche Nullstellen ab.

Fehler 3: Nicht auf „= 0“ gebracht

Bei x² = 4x − 3 zeichnet jemand nur y = x² und liest die Nullstelle 0 ab. Falsch – damit hat er x² = 0 gelöst!

Richtig ist eins von beiden:

  • Rezept A: x² − 4x + 3 = 0 ⇒ Nullstellen von y = x² − 4x + 3
  • Rezept B: Normalparabel y = x² mit der Geraden y = 4x − 3 schneiden

Beide Wege ergeben L = {1; 3}.

Fehler 4: y-Werte als Lösung (Rezept B)

Bei Parabel ∩ Gerade sind die Schnittpunkte zum Beispiel P1(−1 | 1) und P2(2 | 4). Die Lösungen sind −1 und 2, nicht 1 und 4.

Fehler 5: Keine Probe

Ein Kästchen daneben – und schon ist die Lösung falsch. Ohne Probe merkst du das nicht. In der HÜ gibt die Probe oft sogar eigene Punkte.

Faktorisieren

Bau die Gleichung so um, dass links ein Produkt und rechts eine 0 steht. Dann kannst du die Lösungen fast direkt ablesen.

Die Idee: Satz vom Nullprodukt

Wenn du zwei Zahlen multiplizierst und 0 herauskommt, dann muss mindestens eine der beiden Zahlen 0 gewesen sein. Mit lauter Zahlen ungleich 0 kommt beim Malnehmen nie 0 heraus.

Satz vom Nullprodukt

Ein Produkt ist genau dann null, wenn mindestens ein Faktor null ist.

a · b = 0 ⇔ a = 0 oder b = 0

Wann? Der Term sieht aus wie eine ausmultiplizierte binomische Formel: hinten eine Quadratzahl, in der Mitte das Doppelte.

1. binomische Formel

x² + 2bx + b² = (x + b)²

x² + 6x + 9 = (x + 3)²

2. binomische Formel

x² − 2bx + b² = (x − b)²

x² − 10x + 25 = (x − 5)²

3. binomische Formel

x² − b² = (x + b)(x − b)

x² − 49 = (x + 7)(x − 7)

Der 3-Sekunden-Check

  1. Ist die Zahl hinten eine Quadratzahl mit Plus? Dann ist b ihre Wurzel. (25 = 5² → b = 5)
  2. Ist die Zahl vor x genau 2 · b? (2 · 5 = 10 ✓)
  3. Plus vor x → (x + b)², Minus vor x → (x − b)².

Passt Schritt 2 nicht, z. B. bei x² + 10x + 16 (16 = 4², aber 2 · 4 = 8 ≠ 10), dann nimm Werkzeug D.

  1. x² − 10x + 25 = 0

  2. (x − 5)² = 0

    Rückwärts angewendet. Kontrolle: (x − 5)² = x² − 10x + 25 ✓

  3. x − 5= 0|⁠ + 5

    Ein Quadrat ist nur dann 0, wenn die Klammer selbst 0 ist. (Es ist ja (x − 5) · (x − 5) – beide Faktoren sind gleich.)

  4. x = 5

    Diesmal gibt es nur eine Lösung. Die Parabel berührt die x-Achse genau in ihrem Scheitelpunkt.

    Probe: 5² − 10 · 5 + 25 = 25 − 50 + 25 = 0 ✓

D Werkzeug D: Produkt-Summen-Trick

Wann? Die Gleichung hat die Normalform x² + px + q = 0 – alle Glieder sind da, vor x² steht eine 1.

Multiplizier mal (x + 2)(x + 3) aus:

(x + 2)(x + 3)
= x² + (2 + 3)x + 2 · 3
= x² + 5x + 6

Die 5 vor x ist die Summe der beiden Zahlen, die 6 hinten ist ihr Produkt. Rückwärts heißt das: Du suchst zwei Zahlen mit dem passenden Produkt und der passenden Summe.

Produkt-Summen-Trick (Satz von Vieta)

Für x² + px + q = 0 suchst du zwei Zahlen u und v mit

u · v = q   und   u + v = p

Dann gilt (x + u)(x + v) = 0, also x1 = −u und x2 = −v.

Achtung: Die Lösungen haben das umgekehrte Vorzeichen von u und v.

q ist positiv

u und v haben das gleiche Vorzeichen – und zwar das von p.

q ist negativ

u und v haben verschiedene Vorzeichen. Die betragsgrößere Zahl bekommt das Vorzeichen von p.

Zahlenpaar-Finder

Gib p und q ein. Der Finder probiert alle ganzzahligen Paare durch, deren Produkt q ist.

  2. u · v = 6  und  u + v = 5

  3. 1 · 6 = 6, Summe 7 ✗
    2 · 3 = 6, Summe 5 ✓

Weg 3 von 3

Quadratische Ergänzung

Du machst aus der linken Seite eine binomische Formel – danach reicht einmal Wurzelziehen. Dieser Weg klappt bei jeder quadratischen Gleichung.

Die Idee

Manche quadratischen Gleichungen kannst du fast im Kopf lösen. Zum Beispiel diese:

(x + 3)² = 16

Welche Zahl ergibt zum Quadrat 16? Die 4 – aber auch die −4. Also:

x + 3 = 4 oder x + 3 = −4
x = 1 oder x = −7

Jetzt kommt der Clou: Die Gleichung x² + 6x − 7 = 0 hat genau dieselben Lösungen. Man sieht es ihr nur nicht an. Die quadratische Ergänzung verwandelt die eine Gleichung in die andere.

Die Idee in einem Satz

Ergänze die linke Seite so, dass dort eine binomische Formel steht – dann kannst du einfach die Wurzel ziehen.

Vorwissen: die 1. und 2. binomische Formel

(x + b)² = x² + 2bx + b² und (x − b)² = x² − 2bx + b².

Die Zahl vor x ist also immer das Doppelte der Zahl in der Klammer. Rückwärts heißt das: Steht vor x die Zahl p, gehört p2 in die Klammer. Unsicher? Wiederhole kurz die Grundlagen.

Das Bild dazu: Ein Quadrat ergänzen

Warum heißt das Verfahren „Ergänzung“? Stell dir x² + 6x als Fläche vor. Dann fehlt nur noch ein kleines Stück zu einem großen Quadrat. Klick dich durch – und probier auch andere Werte für p aus.

Das Flächenmodell wird geladen …

Für jedes p gilt also:

x² + px + (p2)² = (x + p2)²

Die Zahl, die du ergänzen musst, findest du so: p halbieren, dann quadrieren.

Das Rezept in 6 Schritten

Unter jedem Schritt siehst du ihn gleich am Beispiel 2x² + 12x − 14 = 0.

  1. Normalform herstellen

    Alles auf eine Seite, rechts steht 0. Steht vor x² eine Zahl a ≠ 1, teilst du die ganze Gleichung durch a. Ziel: x² + px + q = 0.

    2x² + 12x − 14= 0| : 2
    x² + 6x − 7= 0

  2. q auf die andere Seite

    Die Zahl ohne x kommt nach rechts. Links bleibt nur x² + px.

    x² + 6x − 7= 0| + 7
    x² + 6x= 7

  3. Ergänzen – auf beiden Seiten

    Halbiere p und quadriere: (p2)². Diese Zahl addierst du links und rechts.

    x² + 6x= 7| + 3²
    x² + 6x + 9= 16

  4. Als Binom schreiben

    Links steht jetzt eine binomische Formel: (x + p2)². Das Vorzeichen in der Klammer ist das Vorzeichen von p.

    (x + 3)²= 16

  5. Wurzel ziehen – mit ±

    Wie viele Lösungen es gibt, entscheidet die Zahl rechts (siehe unten).

    (x + 3)²= 16| √ (±!)
    x + 3= ±4

    x + 3= ±4| − 3
    x= −3 ± 4
    L= {−7; 1}

Halbieren – quadrieren – auf beiden Seiten addieren.

    x² + 6x − 7= 0

    x= 2 ± √5

    Gerundet: x1 ≈ 4,24, x2 ≈ −0,24
    L= {2 − √5; 2 + √5}

    Rechne + 2 – dann steht x allein. Einmal mit +, einmal mit − rechnen: zwei Lösungen. Gib die Lösungen exakt mit Wurzel an. Die gerundeten Werte helfen dir bei der Kontrolle.

    0️⃣Satz vom Nullprodukt

    1Grafisch lösen

    1. Auf die Form … = 0 bringen.
    2. Parabel zeichnen (Wertetabelle).
    3. Nullstellen ablesen.
    4. Probe! (Ablesen ist ungenau.)

    x² − 2x − 3 = 0 → Nullstellen bei −1 und 3 → L = {−1; 3}

    Auf … = 0 bringen → als Produkt schreiben → Satz vom Nullprodukt.

    • Binomische Formel rückwärts:
      x² − 6x + 9 = 0 ⇒ (x − 3)² = 0 ⇒ L = {3}
    • Produkt-Summen-Trick: zwei Zahlen mit Produkt q und Summe p.
      x² + x − 6 = 0: 3 · (−2) = −6, 3 + (−2) = 1
      ⇒ (x + 3)(x − 2) = 0 ⇒ L = {−3; 2}
    • Wurzel ziehen (kein x-Glied):
      2x² − 18 = 0 ⇒ x² = 9 ⇒ x = ±3 ⇒ L = {−3; 3}

    Grundlage für Weg 2

    Satz vom Nullprodukt

    Das Bild

    „Wenn ein Produkt 0 ist, muss einer die 0 mitgebracht haben.“ Bei 3 · 4 · 0 · 7 ist es egal, wie groß die anderen sind – die 0 macht alles zu 0. Und ohne 0 kommt nie 0 heraus.

    So sagst du es

    „In (x − 3)(x + 5) = 0 stehen zwei Faktoren. Einer davon muss null sein. Also fragen wir jeden einzeln: Wann bist du null?“

    Zum Ausprobieren

    Zahlenrätsel: „Mein Produkt ist 0“ gegen „Mein Produkt ist 12“. Beim Produkt 12 gibt es unendlich viele Möglichkeiten (z. B. 3 · 4 oder 24 · 0,5) – deshalb geht der Trick nur mit 0.

    Vorsicht

    Aus (x − 2)(x + 1) = 4 folgt nicht x − 2 = 4. Erst ausmultiplizieren und alles auf eine Seite bringen.

    Weg 2 · Sonderfall

    Wurzel ziehen bei x² = k

    Das Bild

    Zwillinge: 7 und −7 sehen nach dem Quadrieren gleich aus (beide geben 49). Wer rückwärts rechnet, muss beide Zwillinge finden.

    So sagst du es

    „Welche Zahl hoch zwei gibt 49? Der Taschenrechner verrät dir nur eine. Die zweite musst du selbst wissen.“

    Zum Ausprobieren

    Drei Kärtchen: x² = 25, x² = 0, x² = −9. Er soll sie nach Anzahl der Lösungen sortieren: 2, 1, 0. Kein Quadrat ist negativ!

    Vorsicht

    Erst x² allein stellen: 3x² − 48 = 0 → x² = 16 → x = ±4.

    Weg 2 · Faktorisieren

    Der Produkt-Summen-Trick als „Mal-Plus-Rätsel“ (Satz von Vieta)

    Das Bild

    Bei x² + 7x + 12 = 0 suchst du zwei Zahlen, die mal 12 und plus 7 ergeben: 3 und 4. Dann ist x² + 7x + 12 = (x + 3)(x + 4).

    So sagst du es

    „Die Zahl hinten ist das Mal-Ergebnis, die Zahl vor dem x das Plus-Ergebnis. Fang immer beim Mal an – da gibt es weniger Möglichkeiten.“

    Warum es klappt

    Ausmultiplizieren zeigt es: (x + m)(x + n) = x² + (m + n)x + m · n. Die Lösungen sind die Gegenzahlen −m und −n.

    Vorzeichen-Regel

    Mal-Ergebnis positiv → beide Zahlen haben das gleiche Vorzeichen (das der Plus-Zahl). Mal-Ergebnis negativ → verschiedene Vorzeichen, die betragsgrößere Zahl hat das Vorzeichen der Plus-Zahl.

    Rätsel-Generator fürs Kopfrechen-Warm-up

    Weg 3

    Quadratische Ergänzung als Quadrat-Puzzle

    Das Bild

    x² ist ein Quadrat, 6x ist ein Streifen. Halbiert man den Streifen und legt ihn an zwei Seiten an, fehlt nur eine Ecke: 3 · 3 = 9. Ergänzen heißt: die Ecke dazulegen.

    So sagst du es

    „Halbieren, quadrieren, auf beiden Seiten dazuzählen. Dann steht links eine binomische Formel, und du kannst die Wurzel ziehen.“

    Zum Basteln (5 Minuten)

    1. Aus Karopapier ein großes Quadrat schneiden (z. B. 10 × 10 Kästchen) und „x²“ draufschreiben.
    2. Einen Streifen 10 × 6 Kästchen schneiden: „6x“.
    3. Streifen der Länge nach halbieren → zwei Streifen 10 × 3 („3x“).
    4. An die rechte und untere Seite legen. Was fehlt? Ein 3 × 3-Eckstück.
    5. Ecke ausschneiden, andersfarbig anmalen, „+ 9“ draufschreiben. Fertig ist (x + 3)².

    Vorsicht

    Die Ecke ist (p : 2)², nicht p und nicht p². Und sie kommt auf beide Seiten der Gleichung.

    Puzzle am Bildschirm

    Wähle die Zahl vor dem x und geh die drei Schritte durch.

    Weg 1

    Grafisch: Parabel-Schablone basteln

    Das Bild

    Die x-Achse ist die Wasseroberfläche. Die Gleichung fragt: Wo taucht die Parabel ein und wieder auf? Zweimal, einmal (berührt nur) oder gar nicht – genauso viele Lösungen gibt es.

    So sagst du es

    „Lösen heißt hier: Wo ist y genau 0? Lies die x-Werte ab – und weil Ablesen ungenau sein kann, kommt danach immer die Probe.“

    Schablone basteln

    1. Auf Karton (1 Einheit = 1 cm) die Punkte (0 | 0), (±1 | 1), (±2 | 4), (±3 | 9) markieren.
    2. Sauber verbinden, ausschneiden, Scheitel und Symmetrieachse markieren.
    3. Mit der Schablone wird jede verschobene Normalparabel zum Kinderspiel.

    Trick mit Gerade

    x² − x − 2 = 0 umstellen zu x² = x + 2. Dann nur Normalparabel und Gerade zeichnen. Gesucht sind die x-Werte der Schnittpunkte – nicht die y-Werte!

    Alle Wege

    Welcher Weg? Die Fragen-Kaskade

    Bring die Gleichung zuerst auf die Form … = 0 (bzw. auf x² = k). Dann der Reihe nach fragen – die erste passende Antwort gewinnt:

    1. Fehlt der x-Term?→ x² allein stellen, Wurzel ziehen (±).
    2. Fehlt die Zahl?→ x ausklammern.
    3. Binomische Formel zu sehen?→ als Quadrat schreiben.
    4. Klappt der Produkt-Summen-Trick mit ganzen Zahlen?→ faktorisieren.
    5. Sonst:→ quadratische Ergänzung. Die geht immer.

    Grafisch nimmt man, wenn es verlangt ist, zum Überblick oder zur Kontrolle.

    Quadratische Gleichungen lösen durch Faktorisieren

    Satz vom Nullprodukt: Ein Produkt ist genau dann null, wenn mindestens ein Faktor null ist.

    a · b = 0 ⇔ a = 0 oder b = 0

    ① x ausklammern (wenn die Zahl fehlt)

    x² − 4x= 0| x ausklammern
    x · (x − 4)= 0| Nullprodukt
    x = 0 oder x = 4
    L = {0; 4}

    ② Binomische Formel rückwärts

    x² + 6x + 9= 0| 1. binomische Formel
    (x + 3)²= 0| Nullprodukt
    x= −3
    L = {−3}

    x² + 2x − 15= 0| faktorisieren
    (x + 5)(x − 3)= 0| Nullprodukt
    x = −5 oder x = 3

    Sonderfall x² = k: Wurzel ziehen

    • k > 0: zwei Lösungen x = ±√k, z. B. x² = 9 → L = {−3; 3}
    • k = 0: eine Lösung x = 0
    • k < 0: keine Lösung, L = { }

    Hefteintrag 2

    Quadratische Ergänzung

    1. Auf Normalform bringen (durch die Zahl vor x² teilen).
    2. Die Zahl ohne x auf die rechte Seite bringen.
    3. Die Hälfte der Zahl vor x quadrieren und auf beiden Seiten addieren.
    4. Links mit der binomischen Formel als Quadrat schreiben.
    5. Wurzel ziehen (±). Steht rechts 0, gibt es nur eine Lösung. Steht rechts etwas Negatives: L = { }.
    6. Nach x auflösen und L angeben.

    Beispiel

    x² − 6x + 5= 0| − 5
    x² − 6x= −5| + 3² (Hälfte von 6, quadriert)
    x² − 6x + 9= 4| 2. binomische Formel
    (x − 3)²= 4| √ (±)
    x − 3= ±2| + 3
    x= 3 ± 2
    x1 = 5 oder x2 = 1
    L = {1; 5}

    Merke: halbieren → quadrieren → auf beiden Seiten addieren.

    Hefteintrag 3

    Grafisch lösen & welcher Weg wann?

    Die Lösungen von x² + px + q = 0 sind die Nullstellen der Parabel y = x² + px + q.

    Variante: Umstellen zu x² = −px − q. Dann Normalparabel und Gerade zeichnen. Die Lösungen sind die x-Werte der Schnittpunkte.

    Beispiel: x² + x − 2 = 0 ⇔ x² = −x + 2

    Schnittpunkte bei x = −2 und x = 1. Probe: (−2)² + (−2) − 2 = 0 ✓ und 1² + 1 − 2 = 0 ✓. Also L = {−2; 1}.

    2 Schnittpunkte → 2 Lösungen · 1 Berührpunkt → 1 Lösung · kein Schnittpunkt → L = { }
