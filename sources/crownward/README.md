# Crownward

Playable first island of an original side-scrolling kingdom strategy game.

Run `npm ci`, then `npm run dev`. Validate with `npm run typecheck`, `npm test`, `npm run build` and `npm run test:e2e`. The build uses relative asset URLs and can be hosted in a subdirectory.

This publication snapshot includes the complete game source, tests and processed art. Raw image-generation requests and intermediate artwork remain in the canonical development repository. The game supports solo play, local two-player co-op and touch controls; online co-op and a multi-island campaign are not part of this release. Saves live in the browser.
