Worum es in der HÜ geht

Dein Schüler soll quadratische Gleichungen auf drei Arten lösen – ohne Lösungsformel (keine p-q-Formel, keine Mitternachtsformel). Die HÜ ist kurz, also zählt vor allem: den passenden Weg erkennen, sauber rechnen, Lösungsmenge richtig hinschreiben.

📈

Weg 1 · Grafisch

Parabel zeichnen, Nullstellen ablesen – oder Normalparabel mit Gerade schneiden. Immer mit Probe.

🧩

Weg 2 · Faktorisieren

x ausklammern, binomische Formel rückwärts oder Produkt-Summen-Trick, dann Satz vom Nullprodukt. Dazu der Sonderfall x² = k (Wurzel ziehen, ±).

🟧

Weg 3 · Quadratische Ergänzung

Auf eine binomische Formel ergänzen, Wurzel ziehen, nach x auflösen. Funktioniert immer.

Keine Lösungsformel

Falls dein Schüler die p-q-Formel schon kennt (große Geschwister, YouTube): Heute bitte nicht benutzen. Die HÜ fragt ausdrücklich nach den drei Wegen. Gut zu wissen: Die quadratische Ergänzung ist genau der Weg, aus dem die Formel später hergeleitet wird.

Checkliste: Das muss am Ende sitzen

Hak ab, was dein Schüler allein kann. Der Stand wird auf diesem Gerät gespeichert – praktisch für die nächste Stunde.

0 von 10 sicher

Vorher kurz klären

  • Lass dir Heft und Arbeitsblätter zeigen: Welche Schreibweise nutzt die Lehrkraft (L = {…}, x1/x2, „∨“ oder „oder“)? Übernimm sie.
  • Wurde im Unterricht mit Parabelschablone gezeichnet? Wurde der Produkt-Summen-Trick (Satz von Vieta) behandelt?
  • Zählt „Wurzel ziehen“ dort als eigener Weg? Manche Lehrkräfte nennen die drei Wege „grafisch, Wurzel ziehen, quadratische Ergänzung“. Dieser Leitfaden deckt beides ab.
  • Wann ist die HÜ, wie lange dauert sie, ist ein Taschenrechner erlaubt?

Stundenplan

Acht Phasen plus eine kurze Pause, vom Einfachen zum Schweren. Die Reihenfolge ist bewusst: Erst der Satz vom Nullprodukt, weil Faktorisieren darauf aufbaut. Dann die Ergänzung, solange der Kopf noch frisch ist. Grafisch kommt danach als Kontrolle und Abwechslung.

Satz vom Nullprodukt sichern

Ziel: Dein Schüler weiß: Nur wenn auf einer Seite 0 steht, darf man jeden Faktor einzeln null setzen.

Ablauf, Impulse & Material

Du sagst / fragst

  • „Ich denke mir zwei Zahlen. Ihr Produkt ist 0. Was weißt du sicher über meine Zahlen?“
  • „Und wenn das Produkt 12 ist – kannst du dann auch etwas sicher sagen?“ (Nein: 3 · 4, 2 · 6, 1 · 12, (−3) · (−4) …)
  • „Wenn ein Produkt 0 ist, muss einer die 0 mitgebracht haben. Wer könnte das hier sein?“ (auf die Klammern zeigen)
  • „Welche Zahl muss ich für x einsetzen, damit x + 5 null wird?“

Dein Schüler

löst drei Produktgleichungen mündlich, z. B. (x − 2)(x + 6) = 0, x(x − 9) = 0, (x + 1)² = 0, und schreibt eine davon sauber mit „oder“ und L = {…} auf.

Material

  • Erklärstrategie Nullprodukt
  • Übungsblatt Aufgabe 1
  • Kapitel Grundlagen

Stolperstelle: Vorzeichen. Aus x + 5 = 0 folgt x = −5. Lass ihn die Zahl immer einsetzen statt „abzulesen“.

In 60 Minuten: Nur das Zahlenrätsel und zwei Gleichungen mündlich.

Wenn die Zeit knapp wird

Kürze zuerst Methodenwahl und Grafisch – beides lässt sich gut zu Hause mit der Seite üben. Spar nie an der Ergänzung: Sie ist für die meisten der schwerste Teil der HÜ und braucht deine Begleitung.

Diagnose zum Einstieg

Fünf Aufgaben, fünf Minuten. Jede prüft eine Voraussetzung. Die Art des Fehlers sagt dir, wo du ansetzen musst.

D1 Löse: (x − 3)(x + 5) = 0

Richtig: L = {−5; 3}

  • L = {−3; 5} Vorzeichen falsch „abgelesen“ → in Phase 2 immer einsetzen lassen.
  • multipliziert aus, steckt fest Satz vom Nullprodukt unbekannt → Phase 2 ausführlich.
  • nur x = 3 sieht nur eine Klammer → das „oder“ betonen.

D2 Löse: x² = 49

Richtig: L = {−7; 7}

  • nur 7 ± vergessen → fragen: „Was ist (−7)²?“
  • 24,5 verwechselt Quadrieren mit Verdoppeln → Potenzen kurz wiederholen.

D3 Löse: x² − 6x = 0

Richtig: L = {0; 6}

  • nur 6 hat durch x geteilt → „Nie durch x teilen, x ausklammern!“
  • x = ±√6 hat −6x wie eine Zahl behandelt → Termstruktur klären: Was ist x², was x, was Zahl?

D4 Schreib als Quadrat einer Klammer: x² − 8x + 16

Richtig: (x − 4)²

  • (x − 8)² oder (x + 4)² binomische Formeln unsicher → vor der Ergänzung 3 Minuten wiederholen.
  • (x − 4)(x + 4) mit der 3. binomischen Formel verwechselt → alle drei nebeneinander aufschreiben.

D5 Hier ist der Graph von y = x² + 2x − 3. Lies die Lösungen von x² + 2x − 3 = 0 ab.

Richtig: L = {−3; 1}

  • −1 oder (−1 | −4) hat den Scheitelpunkt abgelesen → „Lösung heißt: y ist 0.“
  • Punkt (0 | −3) hat den Schnittpunkt mit der y-Achse genommen → beide Achsen benennen lassen.

Erklärstrategien

Pro Weg ein Bild, das hängen bleibt, ein Satz zum Wörtlich-Sagen und etwas zum Anfassen. Bilder schlagen Regeln – vor allem unter HÜ-Stress.

Grundlage für Weg 2

Satz vom Nullprodukt

Das Bild

„Wenn ein Produkt 0 ist, muss einer die 0 mitgebracht haben.“ Bei 3 · 4 · 0 · 7 ist es egal, wie groß die anderen sind – die 0 macht alles zu 0. Und ohne 0 kommt nie 0 heraus.

So sagst du es

„In (x − 3)(x + 5) = 0 stehen zwei Faktoren. Einer davon muss null sein. Also fragen wir jeden einzeln: Wann bist du null?“

Zum Ausprobieren

Zahlenrätsel: „Mein Produkt ist 0“ gegen „Mein Produkt ist 12“. Beim Produkt 12 gibt es unendlich viele Möglichkeiten (z. B. 3 · 4 oder 24 · 0,5) – deshalb geht der Trick nur mit 0.

Vorsicht

Aus (x − 2)(x + 1) = 4 folgt nicht x − 2 = 4. Erst ausmultiplizieren und alles auf eine Seite bringen.

Weg 2 · Sonderfall

Wurzel ziehen bei x² = k

Das Bild

Zwillinge: 7 und −7 sehen nach dem Quadrieren gleich aus (beide geben 49). Wer rückwärts rechnet, muss beide Zwillinge finden.

So sagst du es

„Welche Zahl hoch zwei gibt 49? Der Taschenrechner verrät dir nur eine. Die zweite musst du selbst wissen.“

Zum Ausprobieren

Drei Kärtchen: x² = 25, x² = 0, x² = −9. Er soll sie nach Anzahl der Lösungen sortieren: 2, 1, 0. Kein Quadrat ist negativ!

Vorsicht

Erst x² allein stellen: 3x² − 48 = 0 → x² = 16 → x = ±4.

Weg 2 · Faktorisieren

Der Produkt-Summen-Trick als „Mal-Plus-Rätsel“ (Satz von Vieta)

Das Bild

Bei x² + 7x + 12 = 0 suchst du zwei Zahlen, die mal 12 und plus 7 ergeben: 3 und 4. Dann ist x² + 7x + 12 = (x + 3)(x + 4).

So sagst du es

„Die Zahl hinten ist das Mal-Ergebnis, die Zahl vor dem x das Plus-Ergebnis. Fang immer beim Mal an – da gibt es weniger Möglichkeiten.“

Warum es klappt

Ausmultiplizieren zeigt es: (x + m)(x + n) = x² + (m + n)x + m · n. Die Lösungen sind die Gegenzahlen −m und −n.

Vorzeichen-Regel

Mal-Ergebnis positiv → beide Zahlen haben das gleiche Vorzeichen (das der Plus-Zahl). Mal-Ergebnis negativ → verschiedene Vorzeichen, die betragsgrößere Zahl hat das Vorzeichen der Plus-Zahl.

Rätsel-Generator fürs Kopfrechen-Warm-up

Weg 3

Quadratische Ergänzung als Quadrat-Puzzle

Das Bild

x² ist ein Quadrat, 6x ist ein Streifen. Halbiert man den Streifen und legt ihn an zwei Seiten an, fehlt nur eine Ecke: 3 · 3 = 9. Ergänzen heißt: die Ecke dazulegen.

So sagst du es

„Halbieren, quadrieren, auf beiden Seiten dazuzählen. Dann steht links eine binomische Formel, und du kannst die Wurzel ziehen.“

Zum Basteln (5 Minuten)

  1. Aus Karopapier ein großes Quadrat schneiden (z. B. 10 × 10 Kästchen) und „x²“ draufschreiben.
  2. Einen Streifen 10 × 6 Kästchen schneiden: „6x“.
  3. Streifen der Länge nach halbieren → zwei Streifen 10 × 3 („3x“).
  4. An die rechte und untere Seite legen. Was fehlt? Ein 3 × 3-Eckstück.
  5. Ecke ausschneiden, andersfarbig anmalen, „+ 9“ draufschreiben. Fertig ist (x + 3)².

Vorsicht

Die Ecke ist (p : 2)², nicht p und nicht p². Und sie kommt auf beide Seiten der Gleichung.

Puzzle am Bildschirm

Wähle die Zahl vor dem x und geh die drei Schritte durch.

Weg 1

Grafisch: Parabel-Schablone basteln

Das Bild

Die x-Achse ist die Wasseroberfläche. Die Gleichung fragt: Wo taucht die Parabel ein und wieder auf? Zweimal, einmal (berührt nur) oder gar nicht – genauso viele Lösungen gibt es.

So sagst du es

„Lösen heißt hier: Wo ist y genau 0? Lies die x-Werte ab – und weil Ablesen ungenau sein kann, kommt danach immer die Probe.“

Schablone basteln

  1. Auf Karton (1 Einheit = 1 cm) die Punkte (0 | 0), (±1 | 1), (±2 | 4), (±3 | 9) markieren.
  2. Sauber verbinden, ausschneiden, Scheitel und Symmetrieachse markieren.
  3. Mit der Schablone wird jede verschobene Normalparabel zum Kinderspiel.

Trick mit Gerade

x² − x − 2 = 0 umstellen zu x² = x + 2. Dann nur Normalparabel und Gerade zeichnen. Gesucht sind die x-Werte der Schnittpunkte – nicht die y-Werte!

Alle Wege

Welcher Weg? Die Fragen-Kaskade

Bring die Gleichung zuerst auf die Form … = 0 (bzw. auf x² = k). Dann der Reihe nach fragen – die erste passende Antwort gewinnt:

  1. Fehlt der x-Term?→ x² allein stellen, Wurzel ziehen (±).
  2. Fehlt die Zahl?→ x ausklammern.
  3. Binomische Formel zu sehen?→ als Quadrat schreiben.
  4. Klappt der Produkt-Summen-Trick mit ganzen Zahlen?→ faktorisieren.
  5. Sonst:→ quadratische Ergänzung. Die geht immer.

Grafisch nimmt man, wenn es verlangt ist, zum Überblick oder zur Kontrolle.

Methoden-Blitz

Gleichung ansehen, Weg antippen – nicht rechnen. Ideal für Phase 6 oder als Warm-up.

Typische Fehler & Gegenmittel

Die zehn häufigsten Stolpersteine. Wenn du einen erkennst: nicht nur korrigieren, sondern die passende Übungsaufgabe direkt hinterherschieben.

FehlerWoran du ihn erkennstWarum er passiertWas hilftÜbungsaufgabe
1 Durch x geteilt x² = 5x → x = 5. Die Lösung 0 fehlt. „Teilen ist doch erlaubt.“ Durch 0 aber nicht – und x könnte 0 sein. Merksatz: „Nie durch x teilen – x ausklammern!“ Probe mit x = 0 machen lassen. x² = 7x
→ L = {0; 7}
2 ± vergessen x² = 16 → x = 4. Nur die positive Lösung. Die √-Taste liefert nur eine Zahl. „Was ist (−4)²?“ Zwillingsbild. Beim Wurzelziehen sofort „±“ schreiben. x² − 25 = 0
→ L = {−5; 5}
3 Nullprodukt ohne 0 (x − 2)(x + 1) = 4 → x − 2 = 4 oder x + 1 = 4. Das Muster „Klammern einzeln gleichsetzen“ ist auswendig gelernt, nicht verstanden. Produkt 4 hat viele Zerlegungen: 1 · 4, 2 · 2, (−1) · (−4) … „Nur die 0 ist magisch.“ (x − 2)(x + 1) = 4
→ x² − x − 6 = 0 → L = {−2; 3}
4 Vorzeichen beim Ablesen (x + 3)(x − 1) = 0 → x = 3, x = −1. Die Zahl wird aus der Klammer „abgeschrieben“ statt die Gleichung x + 3 = 0 gelöst. Jede Klammer als eigene Mini-Gleichung aufschreiben. Oder fragen: „Was muss ich einsetzen, damit die Klammer 0 wird?“ (x + 4)(x − 6) = 0
→ L = {−4; 6}
5 Ergänzung nur links x² + 6x = 7 → x² + 6x + 9 = 7. „Ergänzen“ wird als Umformen des Terms verstanden, nicht als Umformen der Gleichung. Waage-Bild: „Was du links dazulegst, legst du rechts auch dazu.“ Rechenzeichen | + 9 immer hinschreiben. x² + 8x = 9
→ (x + 4)² = 25 → L = {−9; 1}
6 Falsche Ergänzungszahl Bei x² + 6x wird 6 oder 36 ergänzt statt 9. Die Regel „halbieren, quadrieren“ ist nur halb gemerkt. Quadrat-Puzzle: zwei Streifen → halbieren; Ecke ist ein Quadrat → quadrieren. Was ergänzt man bei x² + 10x?
→ 5² = 25
7 Nicht normiert 2x² + 8x − 10 = 0: Produkt-Summen-Trick mit „mal −10, plus 8“ oder Ergänzung mit 4². Produkt-Summen-Trick und Ergänzung (so wie gelernt) funktionieren nur, wenn vor x² eine 1 steht. Erster Schritt immer: „Steht x² allein? Sonst durch die Zahl davor teilen.“ 2x² + 8x − 10 = 0
→ x² + 4x − 5 = 0 → L = {−5; 1}
8 Grafisch: falsche Werte Schreibt y-Werte der Schnittpunkte oder den Scheitelpunkt als Lösung. Oder krumme Werte wie 1,8 ohne Probe. Unklar, was „Lösung“ am Graphen bedeutet. Ablesen ist ungenau. „Lösungen stehen auf der x-Achse.“ Abgelesene Werte immer einsetzen. Zeichne y = x² − 2x − 8, lies ab, mach die Probe.
→ L = {−2; 4}
9 Binomische Formel „vergessen“ (x + 3)² = x² + 9. „Hoch 2 auf jeden Teil“ fühlt sich logisch an. Zahlenbeispiel: (2 + 3)² = 25, aber 2² + 3² = 13. Und das Quadrat-Puzzle: Es sind vier Teile, nicht zwei. Multipliziere aus: (x − 5)²
→ x² − 10x + 25
10 „Keine Lösung“ falsch notiert Schreibt L = {0}, x = √−4 oder „Fehler“. {0} und { } sehen ähnlich aus. Dass ein Quadrat nie negativ ist, ist nicht präsent. „L = {0} heißt: 0 ist eine Lösung. Mach die Probe mit 0!“ Leere Menge als leere Schachtel zeigen. x² + 2x + 5 = 0
→ (x + 1)² = −4 → L = { }

a · b = 0 ⇔ a = 0 oder b = 0

  • k < 0: keine Lösung, L = { }

Hefteintrag 2

Quadratische Ergänzung

  1. Auf Normalform bringen (durch die Zahl vor x² teilen).
  2. Die Zahl ohne x auf die rechte Seite bringen.
  3. Die Hälfte der Zahl vor x quadrieren und auf beiden Seiten addieren.
  4. Links mit der binomischen Formel als Quadrat schreiben.
  5. Wurzel ziehen (±). Steht rechts 0, gibt es nur eine Lösung. Steht rechts etwas Negatives: L = { }.
  6. Nach x auflösen und L angeben.

Beispiel

x² − 6x + 5= 0| − 5
x² − 6x= −5| + 3² (Hälfte von 6, quadriert)
x² − 6x + 9= 4| 2. binomische Formel
(x − 3)²= 4| √ (±)
x − 3= ±2| + 3
x= 3 ± 2
x1 = 5 oder x2 = 1
L = {1; 5}

Merke: halbieren → quadrieren → auf beiden Seiten addieren.

Hefteintrag 3

Grafisch lösen & welcher Weg wann?

Die Lösungen von x² + px + q = 0 sind die Nullstellen der Parabel y = x² + px + q.

Variante: Umstellen zu x² = −px − q. Dann Normalparabel und Gerade zeichnen. Die Lösungen sind die x-Werte der Schnittpunkte.

Beispiel: x² + x − 2 = 0 ⇔ x² = −x + 2

Schnittpunkte bei x = −2 und x = 1. Probe: (−2)² + (−2) − 2 = 0 ✓ und 1² + 1 − 2 = 0 ✓. Also L = {−2; 1}.

2 Schnittpunkte → 2 Lösungen · 1 Berührpunkt → 1 Lösung · kein Schnittpunkt → L = { }
