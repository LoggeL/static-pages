0️⃣Satz vom Nullprodukt

Ein Produkt ist genau dann null, wenn mindestens ein Faktor null ist.

(x + 3) · (x − 2) = 0
⇒ x + 3 = 0 oder x − 2 = 0
⇒ L = {−3; 2}

Klappt nur, wenn auf einer Seite 0 steht!

1Grafisch lösen

  1. Auf die Form … = 0 bringen.
  2. Parabel zeichnen (Wertetabelle).
  3. Nullstellen ablesen.
  4. Probe! (Ablesen ist ungenau.)

x² − 2x − 3 = 0 → Nullstellen bei −1 und 3 → L = {−1; 3}

Variante: x² = x + 2 → Normalparabel y = x² und Gerade y = x + 2 schneiden. Die x-Werte der Schnittpunkte sind die Lösungen.

2Faktorisieren

Auf … = 0 bringen → als Produkt schreiben → Satz vom Nullprodukt.

  • x ausklammern (kein Zahlglied):
    x² − 5x = 0 ⇒ x(x − 5) = 0 ⇒ L = {0; 5}
  • Binomische Formel rückwärts:
    x² − 6x + 9 = 0 ⇒ (x − 3)² = 0 ⇒ L = {3}
  • Produkt-Summen-Trick: zwei Zahlen mit Produkt q und Summe p.
    x² + x − 6 = 0: 3 · (−2) = −6, 3 + (−2) = 1
    ⇒ (x + 3)(x − 2) = 0 ⇒ L = {−3; 2}
  • Wurzel ziehen (kein x-Glied):
    2x² − 18 = 0 ⇒ x² = 9 ⇒ x = ±3 ⇒ L = {−3; 3}
    x² = k: k > 0 zwei, k = 0 eine, k < 0 keine Lösung

3Quadratische Ergänzung

  1. durch a teilen
  2. Zahl nach rechts
  3. (p2)² auf beiden Seiten addieren
  4. binomische Formel
  5. Wurzel ziehen: ±
  6. nach x auflösen
Beispiel: x² + 6x − 7 = 0  | + 7
x² + 6x= 7| + 3²
x² + 6x + 9= 16| binom. Formel
(x + 3)²= 16| √
x + 3= ±4| − 3
L= {−7; 1}

🔁Binomische Formeln

(a + b)²= a² + 2ab + b²1.
(a − b)²= a² − 2ab + b²2.
(a + b)(a − b)= a² − b²3.

Ergänzen: x² + 8x + ? → Hälfte von 8 ist 4, 4² = 16 → x² + 8x + 16 = (x + 4)²

⚠️Top-7-Fehler

  1. ± vergessen: x² = 9 ⇒ x = 3 oder x = −3
  2. Durch x geteilt: dabei geht x = 0 verloren – lieber ausklammern!
  3. Ergänzung nur links addiert – immer auf beiden Seiten!
  4. Vorzeichen: x + 3 = 0 ⇒ x = −3 (nicht 3)
  5. Nullprodukt ohne „= 0“: x(x − 2) = 3 heißt nicht x = 3
  6. Nicht durch a geteilt vor der Ergänzung
  7. Wurzel aus Negativem: x² = −4 ⇒ L = { }, nicht ±2

✅Immer: Probe!

Jede Lösung in die Ausgangsgleichung einsetzen. Links = rechts? Dann stimmt’s.
