Weg 2 von 3

Faktorisieren

Bau die Gleichung so um, dass links ein Produkt und rechts eine 0 steht. Dann kannst du die Lösungen fast direkt ablesen.

Die Idee: Satz vom Nullprodukt

Wenn du zwei Zahlen multiplizierst und 0 herauskommt, dann muss mindestens eine der beiden Zahlen 0 gewesen sein. Mit lauter Zahlen ungleich 0 kommt beim Malnehmen nie 0 heraus.

Satz vom Nullprodukt

Ein Produkt ist genau dann null, wenn mindestens ein Faktor null ist.

a · b = 0 ⇔ a = 0 oder b = 0

Beispiel

Gegeben ist (x − 2) · (x + 5) = 0. Links steht ein Produkt, rechts 0. Also setzt du jeden Faktor einzeln gleich 0:

x − 2= 0|⁠ + 2
x1= 2
oder
x + 5= 0|⁠ − 5
x2= −5

L = {−5; 2}

So gehst du immer vor

  1. Alles auf eine Seite bringen, sodass rechts 0 steht.
  2. Linke Seite als Produkt schreiben – mit einem der vier Werkzeuge unten.
  3. Jeden Faktor gleich 0 setzen und die kleinen Gleichungen lösen.
  4. Lösungsmenge angeben, z. B. L = {−5; 2}, und eine Probe machen.

Achtung

Der Trick klappt nur mit 0 auf der rechten Seite. Bei (x − 1)(x − 2) = 6 darfst du nicht einfach x − 1 = 6 rechnen. Mehr dazu bei den typischen Fehlern.

Bring die Gleichung zuerst in die Form ax² + bx + c = 0. Dann schau, was fehlt oder was dir bekannt vorkommt. Tipp auf eine Karte, um zum Werkzeug zu springen.

A Werkzeug A: x ausklammern

Wann? Das Zahlglied fehlt, also c = 0. Die Gleichung sieht so aus: ax² + bx = 0.

Jeder Summand enthält ein x. Also kannst du x ausklammern – am besten gleich zusammen mit der gemeinsamen Zahl. Schon steht links ein Produkt.

Durchgerechnet: 3x² − 12x = 0

  1. 3x² − 12x = 0

    Rechts steht schon 0, ein Zahlglied gibt es nicht. Das ist ein Fall für Werkzeug A.

  2. 3x · (x − 4) = 0

    3x ausklammern: 3x² : 3x = x und −12x : 3x = −4. Kontrolle durch Ausmultiplizieren: 3x · x − 3x · 4 = 3x² − 12x ✓

  3. 3x = 0  oder  x − 4 = 0

    Satz vom Nullprodukt: Mindestens einer der beiden Faktoren muss 0 sein.

  4. 3x= 0|⁠ : 3
    x1= 0
    oder
    x − 4= 0|⁠ + 4
    x2= 4

    Beide kleinen Gleichungen einzeln lösen.

  5. L = {0; 4}

    Probe: 3 · 0² − 12 · 0 = 0 ✓ und 3 · 4² − 12 · 4 = 48 − 48 = 0 ✓

Noch ein Beispiel: 2x² = 5x

Hier steht rechts noch kein 0. Also zuerst alles nach links:

2x²= 5x|⁠ − 5x
2x² − 5x= 0|⁠ x ausklammern
x · (2x − 5)= 0|⁠ Satz vom Nullprodukt
x1= 0
oder
2x − 5= 0|⁠ + 5
2x= 5|⁠ : 2
x2= 52

L = {0; 52}

Niemals durch x teilen!

Verlockend, aber falsch:

2x²= 5x|⁠ : x  ✗
2x= 5|⁠ : 2
x= 2,5

Die Lösung x = 0 ist einfach verschwunden! Der Grund: Wenn x = 0 ist, hättest du durch 0 geteilt – und das ist verboten. Klammere x immer aus, statt zu teilen.

B Werkzeug B: Reinquadratisch – Wurzel ziehen

Wann? Das x-Glied fehlt, also b = 0. Die Gleichung sieht so aus: ax² + c = 0 – man sagt reinquadratisch.

Bring x² allein auf eine Seite. Dann fragst du: Welche Zahl ergibt quadriert diese Zahl? Meistens gibt es zwei davon, denn 5² = 25 und auch (−5)² = 25.

x² = 25 ⇒ x = ±5 ⇒ L = {−5; 5}

Manche Lehrkräfte zählen das als eigenen Lösungsweg. Egal wie man es nennt – du musst es sicher können.

x² = k mit k > 0

zwei Lösungen

x = ±√k

x² = 0

eine Lösung

x = 0

x² = k mit k < 0

keine Lösung

L = { }

Durchgerechnet: 2x² − 18 = 0

  1. 2x² − 18= 0|⁠ + 18

    Kein x-Glied – Werkzeug B. Ziel: x² soll allein stehen. Dazu kommt zuerst die 18 auf die andere Seite.

  2. 2x²= 18|⁠ : 2

    Jetzt durch die Zahl vor x² teilen.

  3. x²= 9|⁠ Wurzel ziehen, ± nicht vergessen

    x² steht allein. Welche Zahlen ergeben quadriert 9?

  4. x1 = 3  oder  x2 = −3

    √9 = 3 – und weil auch (−3)² = 9 ist, gibt es zwei Lösungen. Kurz: x = ±3.

  5. L = {−3; 3}

    Probe: 2 · 3² − 18 = 0 ✓ und 2 · (−3)² − 18 = 0 ✓

Durchgerechnet: (x − 3)² = 16

  1. (x − 3)² = 16

    Links steht ein ganzes Quadrat. Nicht ausmultiplizieren – direkt die Wurzel ziehen!

  2. x − 3 = 4  oder  x − 3 = −4

    Die Klammer ergibt quadriert 16, also ist sie 4 oder −4.

  3. x − 3= 4|⁠ + 3
    x1= 7
    oder
    x − 3= −4|⁠ + 3
    x2= −1

    Beide Fälle einzeln lösen.

  4. L = {−1; 7}

    Probe: (7 − 3)² = 4² = 16 ✓ und (−1 − 3)² = (−4)² = 16 ✓

Keine Lösung

x² + 4= 0|⁠ − 4
x²= −4

Ein Quadrat ist nie negativ – auch (−2)² = +4.

C Werkzeug C: Binomische Formeln rückwärts

Wann? Der Term sieht aus wie eine ausmultiplizierte binomische Formel: hinten eine Quadratzahl, in der Mitte das Doppelte.

Sonst rechnest du binomische Formeln „vorwärts“ (ausmultiplizieren). Hier gehst du den Weg rückwärts und machst aus der Summe wieder ein Produkt.

1. binomische Formel

x² + 2bx + b² = (x + b)²

x² + 6x + 9 = (x + 3)²

2. binomische Formel

x² − 2bx + b² = (x − b)²

x² − 10x + 25 = (x − 5)²

3. binomische Formel

x² − b² = (x + b)(x − b)

x² − 49 = (x + 7)(x − 7)

Der 3-Sekunden-Check

  1. Ist die Zahl hinten eine Quadratzahl mit Plus? Dann ist b ihre Wurzel. (25 = 5² → b = 5)
  2. Ist die Zahl vor x genau 2 · b? (2 · 5 = 10 ✓)
  3. Plus vor x → (x + b)², Minus vor x → (x − b)².

Passt Schritt 2 nicht, z. B. bei x² + 10x + 16 (16 = 4², aber 2 · 4 = 8 ≠ 10), dann nimm Werkzeug D.

Durchgerechnet: x² − 10x + 25 = 0

  1. x² − 10x + 25 = 0

    25 = 5² und 10 = 2 · 5, vor 10x steht ein Minus. Das ist die 2. binomische Formel!

  2. (x − 5)² = 0

    Rückwärts angewendet. Kontrolle: (x − 5)² = x² − 10x + 25 ✓

  3. x − 5= 0|⁠ + 5

    Ein Quadrat ist nur dann 0, wenn die Klammer selbst 0 ist. (Es ist ja (x − 5) · (x − 5) – beide Faktoren sind gleich.)

  4. x = 5

    Diesmal gibt es nur eine Lösung. Die Parabel berührt die x-Achse genau in ihrem Scheitelpunkt.

  5. L = {5}

    Probe: 5² − 10 · 5 + 25 = 25 − 50 + 25 = 0 ✓

Beispiel mit der 3. binomischen Formel

x² − 49= 0|⁠ 49 = 7², 3. binomische Formel
(x + 7)(x − 7)= 0|⁠ Satz vom Nullprodukt
x1 = −7  oder  x2 = 7

L = {−7; 7}

Das klappt nur mit Minus zwischen den Quadraten. Für x² + 49 gibt es keine binomische Formel.

D Werkzeug D: Produkt-Summen-Trick

Wann? Die Gleichung hat die Normalform x² + px + q = 0 – alle Glieder sind da, vor x² steht eine 1.

Multiplizier mal (x + 2)(x + 3) aus:

(x + 2)(x + 3)
= x² + (2 + 3)x + 2 · 3
= x² + 5x + 6

Die 5 vor x ist die Summe der beiden Zahlen, die 6 hinten ist ihr Produkt. Rückwärts heißt das: Du suchst zwei Zahlen mit dem passenden Produkt und der passenden Summe.

Produkt-Summen-Trick (Satz von Vieta)

Für x² + px + q = 0 suchst du zwei Zahlen u und v mit

u · v = q   und   u + v = p

Dann gilt (x + u)(x + v) = 0, also x1 = −u und x2 = −v.

Achtung: Die Lösungen haben das umgekehrte Vorzeichen von u und v.

q ist positiv

u und v haben das gleiche Vorzeichen – und zwar das von p.

q ist negativ

u und v haben verschiedene Vorzeichen. Die betragsgrößere Zahl bekommt das Vorzeichen von p.

Zahlenpaar-Finder

Gib p und q ein. Der Finder probiert alle ganzzahligen Paare durch, deren Produkt q ist.

Durchgerechnet: x² + 5x + 6 = 0

  1. x² + 5x + 6 = 0
    → p = 5, q = 6

    Normalform, vor x² steht 1. Alle Glieder da – Werkzeug D.

  2. u · v = 6  und  u + v = 5

    Gesucht sind zwei Zahlen. q und p sind positiv – also sind beide Zahlen positiv.

  3. 1 · 6 = 6, Summe 7 ✗
    2 · 3 = 6, Summe 5 ✓

    Teiler von 6 der Reihe nach durchprobieren.

  4. (x + 2)(x + 3) = 0

    Jetzt steht links ein Produkt, rechts 0.

  5. x + 2= 0|⁠ − 2
    x1= −2
    oder
    x + 3= 0|⁠ − 3
    x2= −3

    Satz vom Nullprodukt. Die Lösungen sind negativ, obwohl 2 und 3 positiv sind!

  6. L = {−3; −2}

    Probe: (−2)² + 5 · (−2) + 6 = 4 − 10 + 6 = 0 ✓ und (−3)² + 5 · (−3) + 6 = 9 − 15 + 6 = 0 ✓

Durchgerechnet mit Minus: x² − x − 12 = 0

  1. x² − x − 12 = 0
    → p = −1, q = −12

    Achtung: −x bedeutet −1 · x, also ist p = −1.

  2. u · v = −12  und  u + v = −1

    q ist negativ, also verschiedene Vorzeichen. p ist negativ, also ist die betragsgrößere Zahl negativ.

  3. 3 · (−4) = −12  und  3 + (−4) = −1 ✓

    Paare von 12 durchgehen: 1 und 12, 2 und 6, 3 und 4. Nur bei 3 und 4 ist der Unterschied 1.

  4. (x + 3)(x − 4) = 0

    u = 3 und v = −4 eingesetzt in (x + u)(x + v).

  5. x1 = −3  oder  x2 = 4

    Vorzeichen umdrehen: Welche Zahl macht die Klammer zu 0?

  6. L = {−3; 4}

    Probe: (−3)² − (−3) − 12 = 9 + 3 − 12 = 0 ✓ und 4² − 4 − 12 = 0 ✓

Vor x² steht keine 1?

Dann teile zuerst die ganze Gleichung durch diese Zahl:

2x² − 2x − 24= 0|⁠ : 2
x² − x − 12= 0|⁠ wie oben
(x + 3)(x − 4)= 0

Kommen beim Teilen Brüche heraus (z. B. bei 2x² + 3x + 1 = 0), nimm lieber die quadratische Ergänzung.

Typische Fehler

Diese fünf Fehler kosten in der HÜ die meisten Punkte. Schau sie dir genau an – dann passieren sie dir nicht.

1 Vorzeichen beim Ablesen

Falsch(x + 2)(x − 3) = 0 ⇒ x = 2, x = −3
Richtig(x + 2)(x − 3) = 0 ⇒ x = −2, x = 3

Frag dich bei jeder Klammer: Welche Zahl macht sie zu 0? Bei x + 2 ist das −2.

2 Durch x geteilt

Falschx² = 4x  | : x  ⇒ x = 4
Richtigx² − 4x = 0 ⇒ x(x − 4) = 0 ⇒ L = {0; 4}

Beim Teilen durch x verschwindet die Lösung x = 0. Immer ausklammern!

3 ± vergessen

Falschx² = 16 ⇒ x = 4
Richtigx² = 16 ⇒ x = ±4 ⇒ L = {−4; 4}

Auch (−4)² = 16. Das gilt genauso für (x − 3)² = 16: Daraus folgt x − 3 = ±4.

4 Wurzel aus einer negativen Zahl

Falschx² = −9 ⇒ x = −3
Richtigx² = −9 ⇒ L = { }

Probe: (−3)² = +9, nicht −9. Kein Quadrat ist negativ – also gibt es keine Lösung.

5 Rechts steht keine 0

Falsch(x − 1)(x − 2) = 6

Kurz & knapp

Merke: Faktorisieren

Grundidee: Rechts 0, links ein Produkt – dann jeden Faktor gleich 0 setzen (Satz vom Nullprodukt).

  • AKein Zahlglied: x ausklammern. x = 0 ist immer eine Lösung. Nie durch x teilen!
  • BKein x-Glied: auf x² = k umformen, dann x = ±√k. Ist k negativ: L = { }.
  • CBinomische Formel: (x − b)² = 0 hat nur die Lösung x = b.
  • DNormalform: u · v = q, u + v = p ⇒ (x + u)(x + v) = 0 ⇒ x = −u, x = −v.
