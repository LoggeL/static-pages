# ShareX: Capture without limits

Standalone React/Vite redesign with real-time Three.js sculpture in the original ShareX logo colors, CSS 3D tilt, region selection, callouts, and PNG export.

Run `npm ci` and `npm run build` here, then run `npm run build` at the repository root to update `docs/`.

The demo uses local artwork; it does not capture the visitor's real screen.

Original ShareX logo: https://getsharex.com/brand-assets (SVG preserved unchanged). Motion can be paused; reduced-motion preferences and a non-WebGL logo fallback are supported.
